# Boss 動畫工具（boss_rig）

用設計圖 `docs/art-reference/veltharis-concept.webp`（2026-09-30 第三版：約 5.2 頭身、劍首到下巴、握在握柄上段；一排四個視角：正面、背面、朝右、朝左——設計圖的朝左不用；朝左的成品從朝右的圖層另外組，見「朝左」）做 Boss（Veltharis）的精靈圖。外觀來自設計圖，不花錢（不用 PixelLab）。審查標準照 `docs/animation-review.md`；進度與決定記在 `docs/art-progress.md`「Boss 動畫」。

需要 Python 3 和 Pillow（沒有 numpy）。所有指令在專案根目錄執行。這個資料夾有 `.gdignore`。

## 指令

```bash
python3 tools/boss_rig/reference.py
```

```bash
python3 tools/boss_rig/export_size.py
```

```bash
python3 tools/boss_rig/export_anim.py
```

```bash
python3 tools/boss_rig/checks.py
```

## 受擊、跪地的做法（2026-10-01，`anim_kneel.py`）

**同一個繪製程式**：`anim_kneel.pose_side()`／`front_back()` 是 `anim_walk` 那兩個函式的擴充版；狀態沒有新的鍵時畫出來和 `anim_walk` 逐像素相同（`anim_kneel.verify()`：四種移動的循環、四個方向的站姿都是 0 個像素不同）。所以從站姿、從走路接進來的第一張不會因為換程式而跳。新加的鍵：

- `D` 可以到 43（蹲低）：搬移的範圍跟著放大（`warp()`，原本的 `rig.warp` 只在零件的框外多 16px，移 40px 的零件會被切掉一截）。
- `lx`：額外的前傾（度，負的是往後仰），不跟 `b` 綁。側面照列推移，正面／背面換成列數（6 度 3 列）。
- `bow`：低頭（度，負的是仰頭）。側面把設計圖的頭照脖子轉、重縮（`head_side`，金色細節掉到 85% 以下的角度換成差 1 度的角度）；正面頭往下沉、下巴藏到護喉後面；背面往下沉、藏到披風領子後面。頭晚一張，但**最多晚 2px**（`HEAD_LAG`：跪下時身體一張降 9–10px，晚一整張頭會和身體分開，試過）。
- `planted`：劍是定案站姿的那把（含拳頭），跟著拳頭移動，低於地面的部分在地裡（切掉）。側面前臂在手肘和拳頭之間斜切（`anim_idle.FOREARM`）。`tilt`：劍尖不動、劍跟著手傾斜。`tilt_from`：**劍已經插在地裡**——停在插進去時的深度（`D_KNEEL`）和傾斜，之後手怎麼動都只讓劍繞著入地點傾斜，握劍的手臂伸長或縮短來接（側面斜切前臂、正面把肩甲下面到手肘那一段拉長，`SWORD_ARM`）。
- `sink`：揮下來的劍（`b` < 1）低於地面的部分切掉；它「站姿那一端」換成這一張插地的位置，所以 `b` → 0 時剛好接到插地的劍。
- `pile`、`spread`、`fan`、`cape_up`：碰到地面的布料。側面、正面：還垂著的部分長度不變，碰地之後的折在地面上方幾列（`fold`），側面往後攤、正面往兩側攤；背面：攤在身後地上＝往鏡頭那一側，畫在地面線以下，長度 0.35 倍（`lie`）。正面的前垂布、項鍊也是攤在身前地上（`lie`）。
- `rest`：空著的左手放到立起的左膝上（側面朝左時重擺手臂；正面把前臂壓短、往外移；背面前臂往前伸到身體另一側看不到）。
- `kneeL`、`inL`、`inR`：正面跪姿兩膝分開（左膝往他的左邊 8、左腳 10，右膝往他的右邊 3）。兩膝靠攏時正面看起來像一個矮的人站著，不像跪。
- `ck`：披風下襬被甩（被打中往後仰時往前甩）。`cf`、`ph`：轉場時披風翻飛（往後上方吹起、離地，`CAPE_LIFT`、`CAPE_BACK`、`CAPE_FLAP`、`CAPE_FAN`）。
- `br`：跪著喘氣，胸口和肩膀起伏（插在地裡的劍和拳頭不動，手臂接）。
- `grip3`、`axis3`、`elbow`：被彈開時拳頭的位置（3D 位移）、劍的方向、側面手肘的位置。
- `stand_legs`：腿不動時用定案的腿（短僵直從站姿、跪下的第 1 張），不換成重畫的腿。

**跪姿**（`kneel_legs`，側面模型的單位）：右膝著地在髖的正下方略後（膝蓋關節離地 9.5：畫出來的膝甲最低一列剛好在地面線上；5.5 時陷進地面 4px），小腿沿地面往後、腳尖縮在下面（靴子幾乎直立，`TUCK_PITCH` −70°，腳踝高度 `boot_drop()` 讓腳尖剛好碰地）；左腳平踩在前面 24px，小腿直立，左膝和髖差不多高（大腿往前略往上，這個角色的大腿只有 28.8，跪下時前膝本來就會比髖高）。髖比站著低 `D_KNEEL` = 41px。上身前傾 8°（插劍時 10°），低頭 24°。
- 正面：右腿（畫面左）照定案的腿，大腿直下到膝蓋著地，小腿和靴子往後、被大腿擋住（`_leg_front_k` 的 `cut`；膝蓋還沒著地時靴子畫在膝蓋後面，從膝蓋下面露出來）；左腿（畫面右）膝蓋朝鏡頭、在髖的高度，小腿直立，靴子比地面線低 9px（在前面 24px × 0.35）。立起的膝蓋畫在臀甲和前垂布前面。
- 背面：左腳在前面被身體和披風擋住；右腳縮在膝蓋後面＝離鏡頭近，靴子低 15px，上半被垂下的披風擋住，腳跟和鞋底露在攤在地上的披風上面。
- 跪下（`kneel_down`、`descent_legs`）：右腳踩著腳尖往後滑、膝蓋往下，左腳先往前跨（腳離地）再踩下；腳不會低於地面（`boot_drop`）。

**從移動中失衡**（`walk_kneel`）：被打中那一張是循環那一欄加上往後仰（腿不動、劍還在肩上）；接著劍照停步的路線（`carry.place`，從肩上往上、立在身前、往前往下）8 張繞到身前（太快時劍尖一張移 93px，超過上限 80），同時膝蓋微彎、側移的腳先收到身體下面（4 張內）；劍到地面時插進 15px（那時髖低 15px），然後和站著跪下一樣往下。

**被彈開**（`bounce`）：劍在揮劍路線上（`carry.pose3`：從往前平伸 b=0.34 到肩上 b=1，和起步把劍扛上肩是同一個轉動方向），彈開時劍往上往後越過頭頂、直接落到肩上；拳頭先往前伸（`grip3`）再往上往後。

## 攻擊的做法（2026-10-01，`attack3d.py`、`attacks.py`、`anim_attack.py`）

**先在 3D 定好每個時間點，再投影到四個方向**（animation-review §4.3：四個面向是同一個 3D 姿勢）：

- **關鍵姿勢**（`attacks.py`）：每一個關鍵時間點一組設定——髖往下（`D`）、髖往前（`hx`：重心移到前腳）、**髖轉（`ht`，和 `tw` 同方向：踏步時整個身體跟著轉，每條腿從自己的髖關節接出來，`hip_x()`：右髖往前、左髖往後，各離中線 17px）**、前傾（`lx`）、上身轉（`tw`，+＝往他的左邊轉、右肩往前）、低頭（`bow`）、披風甩（`ck` 側面、`cs` 正面／背面）、右拳的 3D 位置（`fist`）、劍的方向（`dir`：方位角、仰角）、劍面（`flat`／`roll`）、左手握上來沒有（`two`）、兩隻腳（往前、往外、高度、腳掌俯仰）。中間用 Catmull-Rom 內插（數字、拳頭、劍的方向都是），所以一刀揮過去中途不會停；數字在相鄰兩個關鍵姿勢一樣時就停住不動（不會被前後的姿勢帶得超過）。**每隻腳有自己的時間軸**（`Clip.tracks`：關鍵姿勢裡有給那隻腳的、加上 `Clip(..., steps=)` 另外給的起腳、落地時間；關鍵姿勢可以給 `None` 表示那隻腳在空中）：一步可以跨過好幾個上身的關鍵姿勢，在兩個時間點之間走（有抬腳）。腳跟抬起時腳踝自動抬高，讓腳尖留在地上。
- **握法**（使用者 2026-09-30：重攻擊雙手、左手在護手上方）：右拳在握柄上段（劍首旁、和站姿一樣），左拳在它往劍尖 10px（`attack3d.HANDS`）。**這個握法順手的一側是左邊**（靠護手的手在左）：劍在右邊往後指時左手搆不到，所以第一刀的起手是把劍舉在右肩後方（劍尖朝上後方，雙手在右臉旁），第二刀的起手在左肩後方。
- **手臂**（`attack3d.arms`）：上臂 13.5、前臂 15.7、拳頭 6.6（`arm.lengths()`），兩段 IK、手肘往下往外（`POLE`），拳頭太遠時肩膀可以往前 3px（`PROTRACT`）；搆不到就是姿勢錯（`checks_attack` 逐幀檢查）。
- **劍不穿過身體**（`attack3d.body_hits`）：軀幹（橢圓柱）、肩甲（肩關節上方 19px 內：扛劍時劍擱在肩甲上面，不算穿過）、頭盔加王冠，隨上身轉、前傾、蹲低；劍身從護手以上逐點檢查。劍在兩個姿勢之間走人會用的路線：從左邊低處收回右肩，是在身前往上立起、再往後放到肩上（和扛劍起步同一條路）；第二刀舉到左肩，也是先在身前立起再往後；揮到右邊後舉回右肩，是先在肩甲外側抬高、再往後放上去（直接往上會穿過肩甲，檢查抓到）。
- **劍面**：揮砍（劍每幀轉超過約 6°，`attacks.FAST`）時刃在前（劍寬沿著移動方向）；慢的時候照關鍵姿勢的 `flat`：舉在肩後時劍面在「往前」和「往外」之間 45°（`FLAT_R`、`FLAT_L`，和設計圖站姿一樣），四個方向都看得到劍面。之前只照移動方向時，劍舉起來的途中正面變一條線、側面又變寬（劍面在不同方向閃）。
- **選哪幾張**（`attacks.sample`）：從第 0 幀起，盡量少張，但相鄰兩張劍尖在任何一個方向的畫面上移動不超過 68px（上限 80 的 85%）、右拳不超過 13.6px（上限 16 的 85%），每張最多停 6 幀；判定開始、結束、最後一張扛劍一定有一張。揮砍那段因此每幀一張。

**畫**（`anim_attack.py`）：身體、腿、頭、披風的畫法和走路、受擊一樣（整數像素搬移、腿照關節擺設計圖的腿），新加的：

- **手臂**：兩隻手臂都照 3D 擺（`arm.py` 的手臂圖，正面的右手臂和兩個側面是鏡像那張，正面的左手臂用原圖；背面反過來）。每隻手臂從**畫出來的肩膀**開始；**拳頭的位置從劍算**：右拳在握柄點、左拳在握柄點加上 3D 位移的投影——兩隻拳頭一定在同一根握柄上（先前各自從自己的肩膀投影，側面遠側的肩膀畫得比投影高 12px，左拳就離開握柄 12px）。**側面的點（右拳、手肘）用立面投影**（`elevation`：畫面位置不看深度，和扛劍的拳頭 `carry.fist_screen` 一樣；劍的方向才有深度）：側面的站姿是立面圖（兩邊肩膀一樣高），點照深度投影時，朝右的手會比朝左高 14px（各自從近側肩膀算），左右就不對稱了。正面、背面照完整的投影，從畫出來的肩膀算。手肘是 3D 手肘的投影，再拉回骨頭長度以內（`AW.reach`）；前臂朝鏡頭、畫面上比拳頭還短時，手肘推到離拳頭 8.2px（拳頭的長度＋1.6），否則拳頭會被推出握柄外。
- **原本的手臂拿掉**：正面拿掉站姿右上臂（`ARM_OFF`）和垂著的左手臂、背面拿掉兩隻手臂（肩甲 `PLATES` 留著、畫在擺好的上臂上面）；背面手臂後面露出的地方用另一邊的披風左右鏡射補（披風自己的底圖在手臂那裡長成方塊，不用）。
- **劍照深度分前後**（`sword_split`）：劍的每個像素算出它在劍身上的位置 → 3D 點 → 深度：側面看那一點在身體中線的近側還是遠側（遠側畫在披風、身體下面）；正面分三層（身體後面 12px 以外在披風下、身體前後之間在身體下、前面在最上面）；背面兩層。劍幾乎正對鏡頭時整把用同一個深度。
- **上身轉**：正面、背面把腰帶以上每一欄當成橢圓柱的表面轉（`Twist`，往鏡頭轉過來的那一側畫低），只畫 0.7 倍的角度（全畫時肩上的紅布條被拉寬成一塊）；兩個側面不拉伸（拉伸會把肩甲抹糊）：近側肩甲整塊前後移（3D 移動量的 0.35 倍）、胸口 0.2 倍，遠側的肩甲畫一塊暗的在另一邊，轉向鏡頭時從胸口前面露出來。
- **肩膀帶著上臂轉**（使用者 2026-10-01：「手臂都不動，只有手軸在轉動，肩膀都沒有帶著大臂轉，只有小臂在揮」）：
  - 每個關鍵姿勢定兩隻手肘往哪裡（`attacks.with_poles`：`poleR`、`poleL`，3D 方向，內插）：舉在肩後時手肘往外抬到肩膀高度（`OUT_*`）、另一隻手橫過胸前（`ACROSS_*`）、往前伸時手肘往下往外（`DOWN_*`）、揮完時伸直的手臂跨過身體（`CROSS_*`）、彎著的那隻手肘往後（`BEHIND_*`）。原本一律往下垂（`attack3d.POLE`），上臂都藏在肩甲下或指著鏡頭。
  - 肩膀跟著上臂動（`attack3d.girdles`）：上臂抬起時肩膀往上（最多 5px）、往前伸時往前（3.5px）、往外時往外（2px），從扛劍的位置量起（扛劍那一張不動）。

## C4 突刺的做法（2026-10-04，`attacks.thrust`、`thrust_bounce`；`export_thrust.py`、`checks_thrust.py`）

和王權橫掃同一套（3D 關鍵姿勢 → 四方向投影），新加的／不同的：
- **彎腰 `bend`**（第二版，使用者：「突刺的身體還是壓得不夠低，整個身體要彎下去，頭的高度只在劍的上面一點點這麼彎……整個人會因為彎腰變扁」）：原本的前傾 `lx` 是把腰以上每一列往前推（剪切），頭的高度不變，彎不下去。新的關鍵值 `bend`（度）讓腰以上繞著腰帶轉：
  - 3D（`attack3d.bend_point`）：肩膀、頭照轉過的位置算（`shoulder()`）；劍不穿過身體的檢查把點轉回站姿再判斷（`body_hits`）。
  - 側面（`anim_attack.bend_pixels`、`bend_at`）：身體、肩甲、背後的底圖整塊照像素轉（每個像素拆 4×4 取樣，和肩甲轉動同一套），腰帶上方 6px 到下方 2px 漸漸轉（腰彎、髖不轉），轉開的細縫從兩旁補；披風上半跟著肩膀轉、腰以下垂著；畫出來的肩膀照轉過的位置（手臂從那裡接）；頭跟著脖子轉過去，再照 `bow`（負的是抬頭）轉回來看前面（`side_head(..., pivot)`）。
  - 正面／背面：腰以上的列照 `cos − 0.35 sin`（正面：往鏡頭倒，變短）、`cos + 0.35 sin`（背面）壓扁，最多壓到 `FOLD_MIN` 0.45（再壓會變成一條條橫紋）；頭、肩甲不壓，整塊往下移到 3D 算出來的位置（正面頭落到兩個肩甲中間、手臂上方）；正面披風的上緣只跟著往下一半（從正面看得到他彎下去的背和披風；整個往下會變成橫紋，不往下又像頭上頂著一個拱）；背面彎超過 30° 時頭畫在披風和肩甲後面（`BEND_HEAD_BEHIND`）；被輪廓圍住的空隙（正面頭旁邊折掉的胸口）從周圍補（`fill_enclosed`）。圖層搬移範圍放大到 `WHOLE_PAD`（頭往下移 50px 以上）。
  - `bend` 預設 0：王權橫掃、雙斬、快斬、下劈一系列、受擊跪地畫出來逐像素不變。
- **起手照使用者的描述**（2026-10-04 兩次）：`_cocked()`：腰彎 64°、蹲 28、髖往後 12，右拳 (−7, 18, 62)（他右邊、髖前 5px、比頭的中心後面約 30px），劍往前、往左 16°、往下 4°；頭的最低點在劍上面 9–12px；上身往右扭 30°（扭 55° 時右肩跟著彎腰抬到頭上面、像一個駝峰；不扭時左手搆不到、劍會穿過髖）；右腳 `THRUST_RB` 往後 60px（肩寬 41；第一版 44）。**劍是 118px 長**，比彎下去的身體長，手收到髖旁時劍尖還是伸到臉前面約 70px（頭的中心前面 83px）（使用者說「頭幾乎要跟劍尖一樣位置（比劍尖後面一點）」，照劍的長度做不到更近）。
- **蹬地與飛出去**：第 33–35 幀髖往前推、右腳在地上（第 35 幀腳跟抬起，腿伸到 98%）；第 36 幀右腳離地，之後右腿伸在後面、離地 12px；左腳第 36 幀離地、在空中往前跨，第 46 幀落地；第 37–44 幀兩腳都在空中。空中髖抬高 6px（蹲 18–20），劍尖跟著往下斜一點保持在主角高度（`_thrust_out` 的 `dir`）。
- **突進的位移**：`Clip(advance=lunge_advance)`，突進每一幀一個關鍵姿勢、第 48 幀停住一格。遊戲第一幀就移 13.3px，所以突進開頭髖反而落在遊戲位置後面 6–7px，之後每幀最多追 1px（畫面上每張最多 15px；追得快時一張跳 17–20px）。
- **側面的前垂布、身後的底圖**（彎腰時）：前垂布往後甩（披風的 `ck` 乘 `BENT_CLOTH_SWING` 3）、下襬只到原長的 `BENT_CLOTH` 0.75；身後的底圖只畫到腰下 `BENT_BACKDROP` 14px（兩腿張開、飛起來時，原本垂到地上的前垂布和底圖看起來像一根柱子撐著他）。
- **刀鋒朝上下**（`roll` = `EDGE`）；`Clip(lead=False)`：刺擊不讓「刃在前」把劍面轉平。
- **蹲 28px 時側面披風的下襬**：原本的換算（`cape_src` 先猜再修一次）在蹲 28 時讓下襬伸到腳底線下 5px（以前的招最多蹲 16，沒碰到）。蹲超過 `CAPE_EXACT_D`（16）時改用精確的反推；16 以內照舊（其他招逐像素不變）。

## C3 下劈的做法（2026-10-03，`attacks.cleave`、`impact`、`double_impact`、`triple`；`export_cleave.py`、`checks_cleave.py`）

和王權橫掃同一套（3D 關鍵姿勢 → 四方向投影），新加的：

  - 新的關鍵值 `arm_k`（上臂和前臂的倍數，拳頭不變；`attack3d.arm_lengths`、`solve_arm(..., k)`、`anim_walk.reach(..., k)`、`anim_attack.posed_arms`）：最高點 `ARM_K_TOP` 1.45，舉起時從 1 慢慢變長、劈下去時縮回、砍到時是 1（`checks_cleave.arm_k_checks`：最多 1.5 倍、整隻手臂每幀最多變 3px、每一刀砍到時和之後都是原長）。
  - `shrug`、`draw_in`（`attack3d._girdle`）：上臂直直往上時肩膀再往上 `shrug`、往脖子收 `draw_in`（最高點 5、3px），肩甲跟著上去。
  - 雙手停在臉的前上方時，正面看兩條前臂從面罩前面斜過去，整個頭看不見（試過）；停在頭的正上方，前臂在頭的兩側和後面：`anim_attack.behind_head` 判斷前臂、拳頭的中點在頭盔前緣後面、頭的寬度以內時，正面畫在頭下面（只在 `shrug` > 0 時，其他招逐像素不變）。
  - 舉起的路線：劍柄從右肩上方往上、再往內移到頭上（直接往內移，劍會穿過頭盔，3D 檢查抓到），劍一直在身後往上抬。
  - `arm_k`、`shrug`、`draw_in` 預設 1、0、0：王權橫掃、雙斬、快斬畫出來逐像素相同（改完重畫比過）。
- **劍面：刀鋒朝前後**（使用者 2026-10-03：「正面跟背面應該看不到完整的劍身，因為角度是劍鋒朝向前後，所以兩個側面都可以看到劍身沒錯，但前後應該只能看到一條細細的劍身」）：從最高點到拔出地面，劍寬在劍自己的垂直面裡（`attacks.EDGE`：roll 90），正面、背面看是一條細線（劍的厚度），兩個側面看到整片劍身。從肩上拿起來時（劍面朝上平放）在舉起的途中轉成刀鋒朝上（第 0–24 幀）。第一版的 `CLEAVE_CANT`（斜 45°）拿掉了。`checks_cleave.edge_checks`：這段每一張劍寬離開劍的垂直面最多 0.14（8°），而且整招每兩張之間劍面（扣掉劍本身的轉動）最多轉 35°（不閃）。
  - 劍面內插只在相鄰兩個關鍵姿勢轉不到 90° 時才對：雙重衝擊拔劍後把劍從地上掄到頭頂（轉 136°），中間加了一個關鍵姿勢（`DOUBLE_PULL1 + 9`），否則劍面往反方向轉、在中間那張翻出平面。三斬第二刀收尾以後不用「刃在前」（`triple()` 的 `lead=W2 + 12`），否則舉劍一加速劍面就一張轉 61°（第一版就有）。
- **劍插進地面**（`Clip(ground=True)`）：劍的每個像素反推回劍身上的 3D 點（沿著劍、橫過劍），地面以下的不畫（`anim_attack.ground_cut`）；三個方向都用同一套，正面的地面在劍伸出去的地方本來就畫得比較低（縱深）。側面劍靠鏡頭的那一邊照縱深畫低最多 3px，這是透視（§4.4）。
- **插在地上的劍不動**（`Clip(still=True)`）：相鄰兩個關鍵姿勢的拳頭、劍的方向一樣時就停住（原本只有數字會停住，拳頭和劍的方向照前後的關鍵姿勢彎過去，卡住的劍會晃 0.2°）；拔出來那幾幀劍的方向不變、只沿著劍身往後拉。王權橫掃、雙斬、快斬沒有用這個選項，畫出來逐像素不變。

## C6 灰燼迴旋的做法（2026-10-05，`attacks.spin`、`spin_bounce`；`anim_attack.render_spun`；`export_spin.py`、`checks_spin.py`）

- **轉一整圈的畫法**（`Clip(spin=True)`、`anim_attack.render_pose` → `render_spun`）：四個方向的圖各自只有一個面向。身體（髖和上身的平均）轉了 k 個 90° 時，那一列改用「轉 k 次之後的面向」的圖畫（`TURN_ORDER`：朝下 → 朝右 → 朝上 → 朝左，往他的左邊轉一次換下一個），整個 3D 姿勢（拳頭、劍、劍面、手肘、腳）繞垂直軸轉回那個面向的座標（`spun`），`tw`、`ht` 扣掉 90k，剩下的 ±45° 照 `whole_turn` 畫。畫完把劍和手臂的紀錄（`SWORD`、`JOINTS`：檢查和 json 讀的）改存回那一列、那一列的座標（朝左那一列是朝右的空間），劍尖照畫出來的位置換算。轉了整圈（k 是 4 的倍數）只扣掉角度、不換圖。
- **轉身是繞著 Boss 的位置轉**：遊戲不移動他，所以轉身那幾張髖要在原點（`hx` = 0，`spun` 檢查），軸腳（左腳）先踩到身體中線下面（`LPIVOT`：`out` = −17），轉的時候它在每個面向都是同一個位置；右腳在空中照髖的方向繞（`spin_steps` 每幀一個位置）。腳的位置轉面向時照「各自的髖線」換算（`spin_foot`）。
- **轉身中只彎一點腰**（`SPIN_BEND` 10°；轉完才彎到 32°）：彎得深時側面的披風會翻到頭上，換圖的那一張頭頂跳 18–23px。側面畫的殘餘扭轉也只畫到 20°（`SPIN_SIDE_MAX`；其他招仍是 45°）：畫到 45° 時遠側的肩甲跑到頭旁邊。

## C7 墜王之躍的做法（2026-10-05，`attacks.leap`、`leap_bounce`；`export_leap.py`、`checks_leap.py`）

- **劍掛在背上**（`Clip(back=(16, 118))`、`attack3d.back_sword`）：握柄在右肩後上方（上身座標 `MOUNT_GRIP` (−17, 14, 140)），劍身往下斜過背後到左腰後面（`MOUNT_DIR`），劍面貼著背；劍跟著上身整塊動（轉、前傾、彎腰都繞著腰帶整把轉，腰帶以下那段也一起轉，不像 `bend_point` 只轉腰以上）。這段時間右手空著（`posed_arms` 照空手畫，和快斬的左手一樣）。放手和握回的那一幀，手上的劍就在掛的位置（`_slung`）。畫的圖層：正面在披風後面（只看到右肩上方的劍柄和左腰旁的劍尖）、背面在最上面、側面在披風上面身體下面。掛在背上時不做劍穿身體的檢查（固定在身體外面）。

## 動畫的做法（2026-09-30，待機、走路、起步、停步）

**原則：定案的站姿像素用整數像素搬，不重新縮小。** 站姿是從手繪風的設計圖縮出來的，滿是細紋理；把稍微移動過的圖再縮一次，整身的紋理會重新取樣（每一張都在閃）。所以：

- **小動作（呼吸、布料擺動、走路的起伏、正面／背面的腳）**：把定案站姿切成圖層（`labels.py` 的零件分區），每個圖層用整數像素位移；接縫的地方重複或丟掉一列，不內插（`rig.warp`、`rig.row_table`、`anim_walk.piecewise`）。待機第 1 張就是定案站姿，逐像素相同。
- **真的要轉的肢體（側面走路的腿；之後攻擊的手臂、劍）**：從設計圖切零件，在工作解析度（4 倍）照關節旋轉、組好，再走同一個 `boss.stylize()`（`limb.py`）。每一張都重新縮，所以只用在本來就在動的部位。
- **底圖**（圖層移開後露出來的地方）：布料先沿著每一列鏡射自己（`rig.mirror_under`，保留紋理和破爛的下襬），再往外長 4px（`rig.grow_under`）；腿往上鏡射（`rig.extend_up`，被布蓋住的小腿）。底圖一律壓暗 0.8 倍（在上面那個零件的陰影裡；不壓暗的話複製到高光會閃一下）。靴子底下不放布料的底圖（下襬到不了那裡）。
- **走路的腿只有一個模型**（`gait.py`，側面）：步幅、腳在地上的時間、骨盆高度、腳掌的俯仰。側面直接照它擺腿；正面、背面把「往前的距離」乘 0.35 變成畫面上的高低（和主角一樣的縱深比例）。
- **扛在肩上的劍是一個 3D 姿勢，四個方向各自投影**（`carry.py`；使用者 2026-09-30：「兩個動作劍都要橫著扛在肩上，然後一樣要留意劍跟手的四面觀」）：
  - 拳頭在右肩甲前方、肩甲頂的高度（`carry.FIST`：往前 15、往右 23、離地 134.5px）；劍從拳頭往後越過肩甲，往外偏 18°（手比肩甲頂更靠胸口，所以劍往他的右後方伸出去）、劍尖比握把高 6°；**劍面朝上平放**。
  - 朝右：整把劍水平橫在肩上，握把在下巴前方，劍身往後伸出身體 60px 左右；平放的劍從側面只看得到厚度（縱深的 0.35 倍，約 7px）。劍畫在頭的前面、肩甲上緣的後面（肩甲蓋住劍的下緣，看起來是擱在肩甲上）。
  - 朝左：劍在遠側的肩上，畫在身體、披風、頭的後面；看到的是披風毛領後面伸出去的劍身（劍尖比手更遠離鏡頭，所以比朝右高約 23px）和喉嚨前面露出一半的拳頭、劍首。
  - 朝下：劍指向遠處，只看到一半多的長度（0.53 倍），從肩膀往外上方伸出去，看得到整個劍面；劍身和護手在肩甲和頭的後面、披風的前面；握把、拳頭、前臂在肩甲前面，劍首朝鏡頭。

- **側移、後退**（2026-09-30，使用者決定要做）：
  - **後退**＝往前走的腿倒過來走（`loop_state(i, 'back')` 用 `1 − p`）：腳往後伸、腳尖先著地、腳跟最後離地，踩地的腳每張往前 4px；晚一張的零件仍然是照播放順序的上一張算，不會變成早一拍。上身直立，披風不往後飄（被身體往前推一點）。

朝左不是朝右的鏡像。兩個側面都在「朝右的空間」裡組（同一個身體），朝左最後才鏡像（`side.py`）：

- **朝左**（劍在遠側的手）：劍畫在身體和披風後面；站姿時只有握在握柄上的拳頭和手腕從胸口前面露出來（定案站姿的前臂整條墊到身體後面）；靠鏡頭的左手臂空著垂下（`arm.py`，從正面的垂手切的上臂、前臂、拳頭，調亮 1.3 倍到和側面原本的前臂一樣亮），走路時前後擺。
- 扛劍時劍在遠側的肩上：畫在最底層（身體、披風、頭的後面）；劍尖比手**更遠離鏡頭**，所以比朝右時高。握劍的手只畫拳頭（亮度和站姿從胸口前露出的拳頭一樣），露出身體前緣的部分約一半；前臂和手肘在胸口後面，不畫（照投影前臂會在胸口前露出 3–4px 的一條，看起來像胸甲多了一道邊；使用者要的是握劍的手被身體擋住）。
- 設計圖自己的朝左也是「劍在靠鏡頭的手」，幫不上忙。
- 原本舉著前臂的那塊軀幹沒有圖，用它下方 14 列的鎧甲補（`side.TORSO_CLONE`）。

### 握劍的手（2026-09-30，使用者：朝右的拳頭歪掉、沒接好手臂、手臂扭曲；背面的拳頭是豎著的）

原因：劍的圖上帶著站姿那個握劍的拳頭，劍一轉拳頭跟著轉；手臂是一整張圖從肩膀拉到那個拳頭。改成：

- **拳頭屬於手臂，劍從拳頭裡穿過去**：重畫的劍都用去掉拳頭的版本（`sword.clean_sword`：拳頭那幾列換成握柄，護手旁邊的披風、手臂殘塊清掉）。
- **扛劍的手臂**（`arm.py`，上臂、前臂、拳頭各自照關節擺，拳頭在前臂的延長線上、大小不變）：上臂從肩甲底下往前伸到手肘，前臂往上到肩甲前的拳頭。
  - 側面：手肘在拳頭下方 21.7px、後方 5px（`anim_walk.SIDE_ELBOW`）。上臂畫在肩甲下面，前臂和拳頭畫在最上面。
  - 正面：手肘在拳頭下方 21px、外側 5px（`FRONT_ELBOW`）；上臂朝鏡頭所以畫面上很短。順序是手臂 → 握把和劍首 → 拳頭（劍首朝鏡頭，在前臂前面；拳頭握在握把外面）。亮度調成和側面的手臂一樣（`arm.near`）。
  - 背面：手在身前，沿用定案站姿的手臂（只到手肘下方）；拳頭（`arm.fist_only`）和握把畫在最底層，露出肩膀上方的那一截看得到。
  - 起步、停步：手肘在「站姿的手肘」和「扛劍的手肘」之間內插，拳頭跟著劍的握點；內插出來的手肘離拳頭或肩膀太遠時拉回骨頭的長度以內（`anim_walk.reach`：畫面上骨頭可以變短——朝鏡頭——不可以變長）。
- 站姿（b = 0）仍然是定案的圖：拳頭是劍圖上原本那個。第一張過渡起，劍換成去掉拳頭的版本、拳頭由手臂畫。

### 踩過的坑

- 圖層沒畫底圖就直接合成（只畫 `pix` 不畫 `under`）：呼吸時腰帶、靴子上方出現 1px 的透明橫線。靜止的圖層也要用 `Layer.all()`。
- 劍旁邊的零星火焰像素被分到披風：披風的底圖從那一點往劍底下長成一個菱形，劍一動就露出一塊紅色。`labels.absorb_islands` 把小於 12px 的孤島併進周圍的零件。
- 腿的多邊形下緣比腳底高 3 個設計圖像素：腳底最後一列被分到披風，抬腳時留在地上一條黑線。
- 披風的底圖長到靴子底下：抬腳後原地留下一塊橫條紋。底圖在下襬以下清掉。
- 側面腿的零件多邊形沿著腿後緣帶到披風的紅邊：轉動後變成腿上一條紅線。零件在後緣那幾欄去掉紅色像素（`limb.BACK_EDGE`）。
- 側面前垂布的底圖複製到金色吊飾，變成腿後面的金色橫線：側面改用一塊暗色的「兩腿之間」底布（`anim_walk._backdrop`），太亮或金色的像素換成那一列最暗的布色。
- 靴子照腳尖前 2px 的點轉（離地時腳跟抬起）：腳尖會戳進地面 1px。改成照腳尖轉（`gait.BALL`）。腳踝高度要照站姿量（16.27px），用 16 會低 1px。
- （第一版，提著劍走時）劍跟著骨盆整個下沉：骨盆最低時劍尖戳進地面。（第二版改成拖劍；現在是扛劍。）
- 側面前垂布整塊晚一張：骨盆和布之間出現 1px 的縫。布的上緣跟腰帶、下襬才晚一張。

- 投影「點」和投影「方向」要分開：側面的投影有一個基準面的常數（握劍的手那個平面），套到方向向量上劍就被壓成一條直線。方向用 `sword.project_vec`，點用 `carry.fist_screen`。
- 側面起步時劍尖一路貼著腳底線，最後一張才跳到循環的位置（低 10px）：過渡的劍尖高度也要跟著比例內插。
- 劍的滾轉角（劍面朝哪）試過 −60° 到 70°：0°（劍刃朝下）側面看到整個劍面、背面只剩一條線；45° 以上相反。取 12°。
- 側面原本舉起來的前臂後面沒有身體的像素：用它下方 14 列的鎧甲補；前臂超出胸口前緣的部分直接清掉。
- 合成後「布料色」的像素在側面掉到站姿的 62–80%：劍身的紅色也算在裡面，平放的劍從側面只剩厚度（不是簡化）。細節量改成合成前量：扛著的劍的紅色、金色佔它自己像素的比例，是站姿那把劍的 80–115%；合成後的數字只列出來。

- 劍的切圖帶著護手旁邊的披風、手臂殘塊（站姿時被身體擋住看不到）：劍一離開原位就露出一塊暗紅色的方塊。重畫的劍一律用清過的切圖；只有正面、劍還立在身前的那幾張用原切圖（那塊陰影剛好是拳頭和肩膀之間的手臂）。
- 背面把手臂換成「只到手肘」的圖層：手肘下面原本定案站姿有畫的一小段不見了，露出披風的底圖（一塊紅色）。定案的手臂照畫，前臂另外疊上去。
- 兩段骨頭的 IK（上臂、前臂等長不變）在手靠近肩膀時手肘會往後翹成雞翅膀：真實情況是手肘朝鏡頭（畫面上變短）。改成指定手肘的位置、前臂照畫面上的長度畫。

- （扛劍）劍面直立地扛（看得到整個劍面）時，側面的劍有 24px 高，整個頭都被擋住，握把和拳頭剛好在面罩前面。劍面朝上平放才不擋頭；代價是側面只看到厚度。
- （扛劍）拳頭放得太靠前（離中線 15px 以上、前臂直立）：朝左時整條前臂和手肘的護甲尖刺都露在胸口前面。放得太靠後（11px）：朝左只剩一根劍首從喉嚨前面伸出來，看不出是手握著。現在 15px、前臂往後斜、朝左只畫拳頭。
- （扛劍）起步時劍尖一離地就往鏡頭那一側甩，側面的劍尖反而比立著時低 1px（靠鏡頭的東西畫得比較低）：握點跟著抬高，劍尖在畫面上不會低於立著的位置（`carry.place`）。
- （扛劍，第一版）起步時劍走最短的路：劍尖從身側往後上方甩到肩上（96°）。使用者指出不符合人體工學（劍身要穿過手臂和肩甲）：改成從身前往上繞（264°），起步 10 → 12 張、停步 8 → 10 張，畫格用攻擊類的容器。
- （扛劍）劍甩上去時如果劍面不轉（照站姿的 45°），朝右看到的劍幾乎是側對鏡頭的一條線、朝左卻是整個劍面：兩個側面差很多。改成揮動時刃在前（`carry.roll`），兩個側面都看得到劍面。
- （扛劍）緩動用 `smooth()` 時中段太快；改成 `anim_walk.ease`（一半線性）。
- （扛劍）過渡時手肘用內插、拳頭跟著劍走，前臂被拉長到 111%：`anim_walk.reach` 把手肘拉回骨頭長度以內。
- （扛劍）正面的拳頭看起來很暗：量過，定案站姿正面握劍的拳頭本來就這麼暗（亮度 41；重畫的是 57），不是錯。

## 和主角（sprite_rig）不同的做法，為什麼

- **設計圖沒有像素格**：主角的設計圖是規則的像素格（約 4.0×4.4），可以還原成原生像素；Boss 這張的邊緣強度做自相關，哪個方向、哪個視角都沒有週期（`reference.py` 開頭）。所以不還原原生像素，改成「原尺寸切圖 → 工作解析度擺姿勢 → 一次縮到定案尺寸」。
- **工作解析度**：`boss.WORK = 4`，每個定案像素 = 4×4 工作像素。四個視角在設計圖上同一條地面線、同一個比例，所以**全部用正面的比例縮放**（正面王冠尖到腳底 657 個設計圖像素 = `4 × 身高` 列，`boss.sheet_scale()`）；側面的王冠尖刺畫得比較高，縮完也比較高。姿勢、合成都在工作解析度做（平滑取樣沒關係），最後 `boss.stylize()` 一次縮小。所有方向、之後所有動畫幀都走同一個 `stylize()`，外觀和色盤才一致。
- **`stylize()` 分三層**（`boss.py`）：
  - 底層：工作圖先中值濾波（`MEDIAN = 5`）再區域平均縮小。直接平均會把設計圖的紋理雜訊變成滿身斑點（試過：銳化、純平均、中值、中值加去孤點、取眾數，見 art-progress）。
  - 金色層（金邊、骨、劍刃的淺色邊）：工作像素是金色的比例 ≥ `GOLD_MIN = 0.35` 的定案像素改成金色（該格金色像素的平均）。
  - 紅色層（發光符文、面罩十字）：比例 ≥ `RED_MIN = 0.25`。
  - 然後吸附色盤、輪廓邊上來源多半是描邊的改成描邊色、清掉 1–2px 的孤點。
- **色盤**（`palette.txt`，48 色含描邊）：用 OKLab 找最近色；建色盤時分成灰、紅、紫、金四組各自中位切割，每組有最少格數（`GROUP_MIN`）。用 RGB 加權距離＋整體中位切割時，紫色（披風內層、毛領）被併進灰色（第一版設計圖：正面的紫從 8.5% 掉到 4.5%）。改了之後各組比例和設計圖接近，數字記在 art-progress。

## 座標

- 設計圖座標（sheet）：`reference.py` 的常數都用這個（切圖框、劍的輪廓、靴子、握點）。`View.to_work()` 換成某個視角的工作座標（含左右翻轉）。
- 局部座標（local）：`ref/<視角>.png` 自己的像素（＝設計圖座標減掉 `ref.json` 的 `origin`）。`labels.py`、`limb.py` 的多邊形和關節用這個；`rig.Layout` 換成畫格座標。
- 定案畫格：一般動作 256×224、腳底對齊點 (128, 208)；攻擊類 384×336、(192, 272)。工作畫格是它的 4 倍。
- 「身高」＝正面的王冠尖到腳底（`boss.HEIGHT`，使用者定 160px）。

## 清理的細節（`reference.py`）

- **去背**：背景是平的中灰 (40, 42, 46)，和背景差 16 以內、連到圖邊的算背景；再往人物四周較暗的光暈長（`grow_into_halo`：中性灰、亮度 22–50，近黑的描邊擋住）；每個視角用「欄的範圍」（在相鄰兩個人物最接近的欄切開：455、780、1108）加種子填充分開。
- **被圍住的背景**（披風破口、手臂和披風之間、王冠尖刺之間，洪水填充到不了）：和背景顏色接近的連通塊，≥ 60px（靠近下擺 110 列內 ≥ 30px），**而且**平均是中性灰（紅、藍都不超過綠 4）、有 5% 以上和背景幾乎一樣（差 ≤ 5），才清掉（`is_backdrop_patch`）。背面披風中間的深灰紫布和背景差不到 16，只用大小判斷時整塊被挖掉；它偏紫、幾乎沒有和背景一樣的點，所以加了這兩個條件。
- **地面帶**（腳底上方 12 列）：除了靴子、披風下擺和劍尖以外都清掉；腳底以下一律清掉（設計圖的劍尖插進地面，不留）。
- **劍**（`SWORDS`：正面、朝右）：
  - 劍刃的左右邊界每一列自動找：導引輪廓附近 8px 內最外側的「淺色」像素（刃邊是淺米色；火焰的光暈是飽和的紅，不算），±3 列取最寬，再加 2px 描邊。
  - 劍柄、護手、握劍的手是手描多邊形（`hilt`）。`zone` 裡除了劍刃、`hilt`、身體那一側（`body_edge`／`body_side`）以外都清掉。正面的清理範圍在拳頭以上是讓開的（手臂在那裡）；正面劍刃和右腿之間是披風（`blade_edge`：身體從劍刃邊緣開始），上面的火焰條紋用周圍非火焰像素的中位數補（`recolor`）。
  - 單獨的劍（含握劍的拳頭）存成 `ref/sword_*.png`，`ref.json` 記劍首、拳頭（`grip`）、第二隻手的位置（`lower_hand`，護手上方）、劍尖；之後做攻擊時當零件。
