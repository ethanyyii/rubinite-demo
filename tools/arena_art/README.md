# 競技場美術工具（arena_art）

2026-10-05 做的正式場景：森林深處王城廢墟的中庭（`docs/arena.md`）。全部用程式畫（Python＋Pillow，沒有 numpy），
和角色同一種像素大小（畫面 960×540 的 1 像素）、同一種畫風（深色 1px 描邊、石頭照右上方的光打亮、朝上的面長青苔、
藤蔓往下垂）。**畫面上不放任何場景的東西**（使用者 2026-10-06）：每一樣都在世界座標裡。參考圖 `docs/art-reference/arena-concept.webp` 只拿來抓氛圍、顏色、材質，**沒有照抄、沒有從參考圖切任何東西**
（使用者 2026-10-05：參考圖的場景不適合打鬥，要同一種氛圍的打鬥場地）。這個資料夾有 `.gdignore`。

## 指令

```bash
python3 tools/arena_art/arena.py export
```

```bash
python3 tools/arena_art/arena.py mock <資料夾>
```

| 指令 | 作用 |
|---|---|
| `arena.py export`（或不加參數） | 輸出遊戲用的圖到 `assets/sprites/arena/`（版面裡已經沒有的 `prop_*.png` 會刪掉）、版面 `scripts/view/arena_layout.gd`（`ArenaLayout`）。約 1 分鐘。之後 `godot --headless --path . --import` |
| `arena.py mock <資料夾>` | 不寫遊戲的檔，只出四張 960×540 的樣稿（中央、西北、東南、第二階段），用站姿的主角和 Boss 擺在畫面上（只有靜態的圖：光斑、葉子、烏鴉這些會動的東西要在遊戲裡看） |
| `ground.py <輸出.png>` | 只畫地面（不含北邊的廢墟） |

## 踩過的坑

- 石頭用 Bayer 混色時，大片的光斑看起來像紗窗：石頭、土、青苔改用「grain」（每個像素用雜湊決定往哪一階靠），沒有規則的格子。
- 「裂縫」第一版用條紋公式畫在八分之一的石頭上，整片變成磚牆的花紋：改成少數石頭上一條隨機走的細線。
- 陽光的斑點拉得太長、光束又太亮時，整個場地變成斜斜的斑馬紋，比戰鬥還搶眼：光斑改成圓一點的一塊一塊，光束只剩三道、往南淡掉、很淡。
- 角落的枝葉第一版放在世界座標，鏡頭在中間時根本看不到：改成畫面座標加一點視差。**之後使用者整個拿掉（2026-10-06）**：畫面座標的東西會擋視野、不屬於場景。
- 植物擺動的 shader：fragment 裡的 `COLOR` 已經乘過一次圖的顏色，再乘一次 `texture()` 植物全變黑；節點的 modulate 要從 vertex 用 varying 帶過來。擺動幅度要照植物自己的高度（`top_v`）算，照整張圖的高度算永遠不到 1 px。
- 地面節點自己的 `_draw`（旗子的火苗）畫在子節點（地面圖）底下：子節點要 `show_behind_parent`，不然火苗被地面蓋住、看不到（第一版就這樣，沒發現）。
- 黑色的烏鴉停在火盆的鐵碗上看不見：停在淺色的石頭、倒木、草地上。場地外的烏鴉離主角最近也有 90 px 左右，「被嚇飛」的距離要比這個大。
- 錄影腳本連續跑好幾段時，前一段被嚇飛的烏鴉還沒回來：`reset_battle` 讓牠們停回原位。
