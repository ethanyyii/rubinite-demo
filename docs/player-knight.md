# 主角設計：流浪騎士 v0.1（定案）

> 參考圖：`docs/art-reference/player-knight-concept.webp`
> 戰鬥規則見 `combat-design.md`。

## 1. 外觀

- Q 版比例，約 2–3 頭身。遊戲內身高約 40px，Boss 約 120px，比例約 1：3。
- 深色鋼甲，藍色羽飾，破碎的藍色披風。
- 武器：單手長劍，腰間有劍鞘。**不持盾**，用劍格擋與彈返。
- 配色（依設計圖色票）：藍、兩種棕、深棕、灰、淺灰。
- 配色語言：藍色代表他自己，紅色代表執魂。侵蝕以紅色裂紋爬上鎧甲來表現；demo 只在擊敗 Boss 後多一道裂紋。

## 2. 朝向

- 設計圖有正面、側面、背面、反側面四個身體朝向，頭部另有左斜、右斜。
- 遊戲要做四方向還是八方向、左右是否用鏡像，會直接影響美術額度，在美術階段決定。

## 3. 動畫需求

| 動畫 | 用途 | 設計圖 | 備註 |
|---|---|---|---|
| 待機 | 待機 | 有 | |
| 走路 | 移動 | 有 | 奔跑沿用，加快播放 |
| 閃身 | 閃身 | 有（衝刺） | 只需一張衝刺幀，殘影由程式產生 |
| 輕攻擊 | 四段連擊 | 部分（一組普通攻擊） | 需要三組：第 1、3 段共用順斬，第 2 段反手斬，第 4 段大幅度斬 |
| 蓄力 | 重擊蓄力 | 缺 | 可沿用突刺的起手姿勢 |
| 突刺 | 重擊出招、處決 | 有（技能攻擊） | |
| 格擋 | 普通格擋 | **缺，最關鍵** | 雙手橫劍擋在身前 |
| 彈返 | 完美彈返 | 缺 | 格擋姿勢加一格「把劍撥開」的畫格，火花由程式產生 |
| 踉蹌 | 被輕擊打中 | 有（受擊） | |
| 倒地／起身 | 被重擊打中 | 有（倒地） | 起身可倒放，或用「蹲下」當過渡 |
| 架勢崩潰 | 架勢歸零 | 部分（蹲下） | 單膝跪地、身體搖晃 |
| 治療 | 使用治療 | 缺 | 可用蹲下＋程式光效 |
| 死亡 | 死亡 | 沿用倒地 | 加上淡出 |

- 設計圖中的「跳躍」不需要，遊戲沒有跳躍。
- 合計約 12 段獨立動畫（每個朝向各一套）。

## 4. 特效

- 藍色刀光：沿用設計圖「技能攻擊」的特效風格。
- 完美彈返：劍與劍碰撞的白金色火花。
- 受擊：紅色閃光。
