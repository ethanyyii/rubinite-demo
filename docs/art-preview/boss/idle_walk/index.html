Boss（Veltharis）待機與移動

還沒接進遊戲。四個方向：朝下、朝右、朝上、朝左。所有移動（往前走、後退、左右側移）都把劍橫著扛在右肩上：劍身平放在肩甲上、劍尖朝後、右手在肩膀前握著握柄。劍一律在右手：朝左時右手在遠側，劍和握劍的手被身體擋住，靠鏡頭的左手是空的（不是朝右的鏡像）。劍上的火焰、符文發光之後由程式畫，這裡沒有。

影片裡 Boss 留在原地，地面照遊戲裡的速度（每秒 60px）往反方向移動，只有 Boss 真的在移動時才動；地上的記號每 40px 一條（一步）。

扛劍的姿勢：四個方向

握劍的手（放大 5 倍）

往前走：從站著到走、再停下來

站著 → 起步（劍從身前往上繞一圈扛到肩上、身體前傾）→ 走 → 停步（收腳、站直，劍從肩上舉起、在身前繞下來立回地上）→ 站著。


往前走的循環：緩步（每秒 60px，一步 0.67 秒）

往前走的循環：快步（每秒 120px，同一組圖播快一倍）

側移：面向主角，往他自己的右手邊走

站著 → 起步 → 側移 → 停步 → 站著。「朝下」就是主角在畫面下方、Boss 面向下方，往畫面左邊走（他的右手邊）；「朝右」時他的右手邊是靠鏡頭那一側，所以往畫面下方走。
