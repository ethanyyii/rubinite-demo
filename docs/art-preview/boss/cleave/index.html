Boss（Veltharis）C3 下劈：墜誓下劈、灰燼衝擊、三斬

還沒接進遊戲。雙手把劍從肩上舉過頭頂（雙手在王冠上方，劍往後倒在頭的上方，刀鋒朝前後：側面看到整片劍身，正面、背面只看到一條細細的劍），身體往後挺；手臂短、頭盔大，照真的手臂長度雙手只到額頭，所以舉過頭的那段手臂畫長（最多 1.45 倍，劈下去時縮回原長）；劈下時右腳踏出、和砍到同時落地，重心壓到前腳、上身前傾；劍尖在判定期間經過 165px、主角的高度，接著砍進地面卡住（收招一開始劍卡在地上不動）；之後重心退回左腳、把劍沿著劍身拔出來，立在右肩前、放回肩上，右腳收回。延遲版用同一組圖，最高點那一張多停 0.6 秒。灰燼衝擊（不可格擋）是插劍：劍從肩上繞到身前、劍尖朝下，雙手把劍舉過頭頂，舉著劍蓄力 0.6 秒（蓄力一開始頭盔的十字閃一下紅光），再站著把劍插進身前的地面（衝擊環從 Boss 擴散）；二階段的雙重衝擊劍留在地上，第二個環前十字再閃一次，全身往下壓放出第二個環。三斬是雙斬的兩刀接下劈：第二刀揮完後左腳收回、劍從右邊舉到最高點，之後和下劈一樣。四個方向：朝下、朝右、朝上、朝左（朝左不是鏡像）。刀光、劍身符文、白光預兆、衝擊環、地面的裂痕由程式畫，這裡沒有。

遊戲裡會看到的順序

墜誓下劈（一階段）：扛劍站著 → 起手 1.0 秒（0.8 秒舉到最高點）→ 判定 0.1 秒 → 收招 1.2 秒（劍卡在地上）→ 扛劍站著


延遲版：舉到最高點停住 0.6 秒（完全不動；劍身符文閃爍由程式畫）→ 劈下（總起手 1.6 秒）


二階段：收招縮短成 0.9 秒（同一組圖）


往前走時出招（從走路循環第 10 張直接接下劈）


側移時出招（從往左側移的循環第 5 張直接接下劈）


在砍到的那一刻被完美彈返：被彈開 1.2 秒 → 扛劍站著


灰燼衝擊（一階段，不可格擋）：劍從肩上繞到身前、舉過頭頂 → 舉著劍蓄力 0.6 秒，蓄力一開始頭盔的十字閃一下紅光（十字形的光芒由程式畫，這裡畫的是示意）→ 站著把劍插進地面、衝擊環擴散（由程式畫）→ 收招 1.4 秒 → 扛劍站著


雙重衝擊（二階段）：插地 → 劍留在地上，第二個環的蓄力一開始十字再閃一下 → 全身往下壓、放出第二個衝擊環（劍不拔出來）→ 收招


三斬（二階段）：雙斬兩刀（第二刀前遊戲把 Boss 往前移 28 px）→ 第二刀之後 1.0 秒下劈 → 收招 0.9 秒
