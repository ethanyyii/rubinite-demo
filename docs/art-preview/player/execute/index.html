處決：躍起下刺（3 秒）

Boss 跪地失衡時在他身邊按攻擊：騎士衝上前、壓低身體、躍起，雙手把劍反握舉過頭，從上面把劍插進 Boss 的胸口／肩頸，掛在劍上往下壓、把劍轉兩次（每轉一次 Boss 抽一下、傷口噴火星），然後一腳蹬在他身上把劍拔出來往後跳，蹲著落地、站起來。整段 3 秒，傷害在劍插進去的那一刻（0.8 秒）。Boss 的反應用之前核准的「被處決」那幾個姿勢，只是拉長、對齊新的時間。
