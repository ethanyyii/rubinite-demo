# 世界觀草稿 v0.2（完整遊戲用，戰鬥 demo 不需要）

> 狀態：規劃討論的歸檔，尚未定案。戰鬥 demo 只取其中的最小子集：以劍彈返的騎士、執魂 Boss 的視覺語言。

## 世界與規則

- 中世紀異世界，劍與魔法。
- **殘響**（現象）：生者未了的執念，死後會留下回聲。
- **執魂**（個體）：殘響凝聚後附身在容器上形成的實體。容器不限：鎧甲、野獸、雕像都可以。
  - 外觀：縫隙冒出紅火；面部只有深邃的黑暗與紅色的光；火越旺代表附身越深。
  - 保留容器生前的本能，招式來自執念；Boss 所在的地方就是執念發生的地方。
- **餘燼**（結果）：執魂被擊敗後留下的東西。
- 反派不是某個人物，而是世界的規則：任何人的執念都可能化為執魂。
- 配色語言：藍色代表主角自己，紅色代表他人的執念。

## 主角

- 流浪騎士，以劍格擋與彈返為核心戰鬥手段，不持盾。藍色羽飾與披風。
- 他能承接餘燼。吸收後會變強（類似技能點），但也被他人的執念侵蝕：紅色裂紋一點一點爬上藍色的騎士，他越來越像他打倒的執魂。
- 不吸收的話，餘燼會波及周圍的事物，所以他選擇承擔。周圍的人不知道餘燼的存在，只看到他一次次打倒怪物、越來越強，看不到他早已不是原來的人。
- 他害怕的是：變得極強，卻成為被別人執念操控的傀儡。
- 最終 Boss：他內心最害怕的自己，也就是被紅色吞沒、同樣以劍彈返的鏡像騎士。

## Boss 構成

- 大多數是各種容器的一般執魂。
- 少數是**前任搬運者**：過去同樣承接餘燼、最後被執念淹沒的人，職業不限，身上帶著共同的標記。
- Demo Boss：Veltharis，The Fallen Oath。曾是國王，如今是一具容器，守著早已化為灰燼的王座。設計見 `boss-veltharis.md`，參考圖見 `art-reference/veltharis-concept.webp`。
- 競技場邊緣插著的斷劍，可以作為過去挑戰者（甚至前任搬運者）的環境敘事。

## 故事結構

- 主角流浪於不同村落與城鎮，每個地方是一章：一個在地事件、一隻執魂。
- 沒有明說的終極目標，目標在旅程中逐漸成形，越往後越明顯，直到最後必須面對。
- 每一章同時推進在地故事與一塊累積線索（侵蝕程度、前任搬運者的標記等），讓玩家感覺得到自己在往某處走。
- 村民是「不知情的人」，他們看著主角到來、解決事件、離開。

## 未決事項

1. 主角的起點與獨特性：
   - A. 他在重要的人臨終時接住了那份執念，循著執念的碎片流浪。
   - B. 他身上附著一隻不肯離去的執魂，替他彈返。
   - C. 他天生沒有強烈的執念，所以能容納別人的執念，也最容易變成傀儡（規劃時推薦，可與 A 結合）。
2. 吸收餘燼是註定的悲劇，還是玩家可以拒絕的真正分歧。
3. 是否加入「力量變強的同時，操控出現微小偏差」的設計。
4. 前任搬運者的共同標記長什麼樣子。
5. 終局 Boss 的具體形式，例如是否會使出前面所有 Boss 的招式。
6. 主角面對村民時的性格（沉默寡言、溫和會笑、隨性不正經）。
