**你是「規劃端」，不是「建置視窗」。** 這個專案有兩種 Claude Code 工作階段：
- **建置視窗**：直接開在 `~/Documents/rubinite-demo` 這個資料夾，讀 `CLAUDE.md`，實際動手做（寫程式、畫動畫）。使用者會親自跟它互動、判斷品質好不好、直接叫它改。

這個分工是使用者在 2026-09-28 明確要求的，不要自己又退回去審查每個技術細節。

**開工前**：先跑 `cd ~/Documents/rubinite-demo && git log --oneline | head -10` 和讀 `docs/art-progress.md` 開頭的「目前狀態」，確認下面的階段狀態還準不準——這份文件是在 2026-09-30 寫的，使用者可能已經跟建置視窗又推進了很多，不要假設這裡寫的就是最新狀態。

## 已決定、排在後面的待辦（2026-09-30，使用者拍板）

**A. 蓄力重擊（突刺）加強——機制修改，等 Boss 美術做完後再做。**
- 問題：現在重擊很弱（蓄力 0.9 秒、突刺 72px、削韌 15、不可取消），玩家沒有使用的理由。
- 設計：突刺距離加長，**近距離蓄力時可以穿過 Boss、落到背後**；**遠距離蓄力時距離不足以穿過，停在 Boss 面前，但位置較安全**。距離與時機就是玩家選擇重擊的理由。傷害與削韌小幅提高（削韌目前 15，例如提到 20–25，數值依手感指標定並記進 `tuning-log.md`）。
- **限制（使用者明確要求）**：
  - **突刺全程沒有無敵。** 目的是不讓蓄力變成 OP、不變成蓄力遊戲，保留「彈返近戰」的核心特色。
  - **距離不能太遠。** 不能長到和 Boss 體型／間距一樣離譜，否則會變成一直拉開距離用突刺的強招。
- 動到的東西：`combat-design.md` §8.2、突刺判定與位移、突刺動畫的位移距離與落點（美術要配合改）、相關測試（★ 規則要重跑）。
- 為什麼排後面：平衡要在 Boss 有正式體型與招式節奏後才調得準，先調會白工。

**B. 專門的處決動畫——排在後面。** 目前處決暫時沿用突刺動畫，可以接受；之後再做專屬處決動畫。

**C. 特效不做專門一批（使用者 2026-09-30 判斷現況可以）。** 只在有具體不滿意處時小修（例如受擊閃紅、蓄滿閃白整隻變色太搶眼）。
